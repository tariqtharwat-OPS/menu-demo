# menu-demo

A fictional Makassar QR menu and one-page site sample. **DEMO only**: all business details, prices, contact actions, hours, addresses and menu details are made up. No customer or client data is included. Food photographs were AI-generated for illustration and do not depict actual products. The WhatsApp action opens a prefilled message draft and does not send it.

Menu edits: update `menu.json`; the static site reads that file. For a real client, replace and verify all details and photos with the owner's approval, replace the WhatsApp number, and test every link. GitHub Pages hosting is free on this public demo. Operational promise for a client would be edits within 24 hours after approved content is received; this is a response target, not uptime/support SLA.
